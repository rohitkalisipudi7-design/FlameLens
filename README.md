Data, scientific models, and interactive dashboard for the challenge *"Flame in Freefall: AI-Powered Fire Safety Insights from Microgravity Combustion Data"*.

## Data Ingestion & Provenance

- **NASA Physical Sciences Informatics (PSI)** comprises ~13.5 TB in total, primarily raw video (`.mp4`, `.ts`) and raw imaging matrices. This repository downloads all metadata, structured experimental matrices, technical publications (≤40 MB), and reduced tabular files (≤2 MB in *Raw Data*). Every file is registered in `files_manifest.csv` with its official AWS `s3_key` for targeted retrieval (e.g., retrieving specific FLEX video runs for computer vision).
- All public NASA PSI files are released under the **CC0 public domain dedication** and require no authentication.
- **Legacy 404 Recovery**: Approximately 2,600 historical records from early campaigns returned 404 on NASA servers (`data/psi/_errors.log`), primarily from FLEX-2. `scripts/recover_psi_from_zips.py` recovered 978 records by programmatically extracting structured `.txt` readings directly from archive `.zip` files without downloading bulk video images. Approximately 1,600 non-critical raw telemetry and proof sheet records lack server-side backups.
- **SLICE (PSI-106)**: Approximately 23,000 `.dat` raw image matrix files (~7 GB) were intentionally bypassed in favor of calibrated scalar reduction tables.
- **NASA Open Data Portals**: `data.nasa.gov` and `science.data.nasa.gov` point to the authoritative PSI repositories under official DOIs (`10.60555/...`).
- **SoFIE / MIST / Confined Combustion**: Investigations actively operating on the ISS without final public PSI ingestion are cataloged through NASA NTRS (`data/ntrs/sofie/`) and NASA Task Book records.
- **MAPTIS**: NASA's Materials and Processes Technical Information System is access-controlled and was excluded to maintain 100% public reproducibility.

### 2. Scientific Data Cleaning Principles (`scripts/clean_psi.py`)

The pipeline processes all 20 NASA PSI experimental matrices and outputs into `data/clean/`:

- **Zero Silent Corrections**: Every normalized, interpolated, or suspicious value logs an explicit `column:reason` marker in `qc_flags` (e.g., `thickness_mm:missing_decimal` for the `037 mm` entry in SAFFIRE-II). No empirical rows are silently dropped; `excluded = true` is strictly reserved for exact duplicate entries.
- **Full Traceability**: Every row retains its immutable `source_file` and `source_line` pointer back to the raw NASA PSI file.
- **Standardized Physical Units**: Pressure in `atm`, ambient mole fractions in `[0, 1]`, lengths in `mm` / `cm`, temperatures in `K`, and ISO 8601 timestamps. When an experimental table omits the calendar year, the date field remains empty rather than fabricated.
- **Three Core Combustion Regimes**:
  1. *Droplets* (FLEX, CFI): $d^2$-law burning rate constants, extinction diameters, cool flame transitions.
  2. *Gaseous Flames* (ACME Flame Design, ACME CFI-G, SPICE): soot generation, flame length, radiative loss.
  3. *Solid Materials* (SAFFIRE I–III, BASS, BASS-II): flame spread rates, sample thickness, concurrent flow.
  - Aerosols (SAME, SAME-R, DAFT) and daily session logs (SLICE, ACME BRE/CLD/E-FIELD/s-Flame) are partitioned into specialized operational tables.
- **Strict Schema Enforcement**: The build halts if any encountered column or flag is missing from `scripts/cleaning/schema.py`, guaranteeing that `data_dictionary.md` remains complete and synchronized.

## Machine Learning & Scientific Analytics

### Fuel-Specific Gaussian Process Regression (GPR)

Flame in Freefall implements fuel-specific Gaussian Process Regression models with anisotropic RBF kernels combined with a WhiteKernel to capture observational noise:

$$\mathcal{GP}\left(m(\mathbf{x}), k(\mathbf{x}, \mathbf{x}') + \sigma_n^2 \delta_{ij}\right)$$

- Features: Chamber Pressure ($P$), Oxygen Mole Fraction ($X_{\text{O}_2}$), Initial Droplet Diameter ($d_0$), and Effective Gravity ($g$).
- Target: Burning Rate Constant ($K \text{ in } \text{mm}^2/\text{s}$) and Extinction Diameter Ratio ($d_{\text{ext}} / d_0$).
- Epistemic Uncertainty: Evaluates predictive variance $\sigma^2(\mathbf{x})$ across parameter space, enabling rigorous quantification of model confidence versus experimental extrapolation.

### Bayesian Expected Information Gain (EIG) Experimental Optimizer

The project features a closed-loop active learning optimizer using Pointwise Mutual-Information Expected Information Gain:

$$\text{EIG}(\mathbf{x}) = \frac{1}{2} \log\left(1 + \frac{\sigma_{\text{pred}}^2(\mathbf{x})}{\sigma_n^2}\right)$$

This identifies optimal high-value experimental candidates that maximize scientific knowledge gain while respecting spaceflight safety envelopes ($P \le 3.0\text{ atm}$, $X_{\text{O}_2} \le 0.30$).

### Cantera Chemical Kinetics Verification

To verify detailed chemical kinetics against empirical microgravity observations:

```python
import cantera as ct

# Evaluate methane-air laminar flame speed at atmospheric conditions
gas = ct.Solution("data/mechanisms/gri30.yaml")
gas.TPX = 300, 101325, "CH4:1, O2:2, N2:7.52"
flame = ct.FreeFlame(gas, width=0.03)
flame.solve(loglevel=0, auto=True)
print(f"Laminar Flame Speed: {flame.velocity[0]:.3f} m/s")  # ≈ 0.385 m/s
```

*Note*: `gri30.yaml` is optimized for light hydrocarbon gases ($C_1$–$C_3$). Liquid droplet fuels utilized in the FLEX investigations (n-heptane, decano, methanol) utilize the San Diego mechanism (`sandiego20161214.yaml`).

## Interactive 3D Combustion Laboratory

The frontend application (`app/`) features an interactive 3D recreation of the **Combustion Integrated Rack (CIR)** and the **Multi-user Droplet Combustion Apparatus (MDCA)** onboard the International Space Station:

- **Physics-Informed Visualizer**: Illustrates the $d^2$-law droplet burning lifecycle ($d^2(t) = d_0^2 - K \cdot t$), ignition transients, hot flame envelope, cool flame transition, and radiative extinction.
- **Continuous Partial Gravity Control**: Dynamically scales buoyant deformation, soot trail advection, and droplet flattening across microgravity ($0g$), Lunar gravity ($0.16g$), Martian gravity ($0.38g$), and Terrestrial gravity ($1.0g$).
- **Instrument Camera Emulation**: Switch between MDCA Color Camera (4:3), HiBMS Backlit Shadowgraphy, and Low-Light Ultraviolet (LLUV) OH* chemiluminescence views.
- **Scientific Integrity**: The 3D visualization is explicitly designated as an educational and exploratory visual simulator, not a CFD Navier-Stokes numerical solver.

To launch the web dashboard:

```bash
cd app
npm install
npm run dev
# Open http://localhost:5173
```
